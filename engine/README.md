# Дашборд «Инфлюенс-маркетинг Биокинетика» — передача коллеге

Что это: один HTML-файл, который открывается в браузере без интернета и показывает
факт и план по рекламе (посев у блогеров, внутренняя реклама маркетплейсов, боты)
в четырёх разрезах — площадка, канал, активность, продукт.

Файл не «живой». Он не ходит никуда за данными сам. Внутри него уже зашит
готовый срез. Чтобы обновить цифры — надо пересобрать файл (см. «Как обновить»).

---

## 1. Что лежит в архиве

```
dashboard-influence.html      ← готовый дашборд, открывается двойным кликом
PROMPT.md                     ← это вставить первым сообщением в свой Claude
LOGIC.md                      ← вся логика расчётов, правила данных, что откуда берётся
engine/
  build.py                    ← сборщик: читает таблицы → собирает дашборд
  template.html               ← шаблон дашборда (вёрстка + графики + вся логика отображения)
data/
  tables/                     ← исходные таблицы менеджеров и выгрузки площадок
    01_elena_influence.xlsx         таблица Елены (инфлюенс)
    02_maria_influence.xlsm         таблица Марии (инфлюенс)
    03_anastasia_marketplace.xlsx   таблица Анастасии (внутренняя реклама WB/Ozon)
    04_anya_external_and_bot.xlsx   таблица Ани (внешний трафик + закупка в ботах)
    05_mediaplan.xlsx               общий медиаплан, лист «План упрощённый»
    06_bot_umny_sad.csv             закупка по боту «Умный сад»
    07_wb_export.xlsx               выгрузка WB (лист «Товары»)
    08_ozon_export.xlsx             выгрузка Ozon (лист «По товарам»)
    09_ozon_export_fresh.xlsx       свежая сводка Ozon за последние дни
  api/                        ← снимки данных из API за период (json)
    ozon_utm.json, ozon_utm_deep.json, ozon_ads.json, ozon_orders.json,
    wb_ads.json, wb_funnel.json, rating.json, shortlinks.json
```

## 2. Что нужно подключить в своём Claude

**Обязательно для пересборки с текущими данными: ничего.** Снимки API уже в архиве,
таблицы тоже. Достаточно Claude с доступом к файлам (Cowork / Claude Code) и Python
с библиотекой `openpyxl`.

**Нужно, если хочешь тянуть свежие цифры из кабинетов:**

| Коннектор | Зачем | Как получить |
|---|---|---|
| Ozon MCP (Seller API + Performance API) | заказы, суммы заказов, выкупы, рейтинг, внутренняя реклама, внешний трафик по UTM-меткам | нужны свои ключи кабинета Ozon: Client-Id + Api-Key с ролью «Admin read only», и отдельно пара Performance API |
| Wildberries MCP | воронка (заказы/выкупы/суммы), внутренняя реклама, отзывы и рейтинг | персональный токен кабинета WB со всеми правами на чтение |
| Google Drive (опционально) | читать таблицы менеджеров прямо из Google Sheets, не скачивая вручную | подключить коннектор Google Drive и расшарить папку с таблицами на тот аккаунт |

Важно про лимиты — это не мелочь:
- **Wildberries**: жёсткие лимиты. Один WB-инструмент за один ответ, пауза 25–35 секунд между вызовами. Поймал 429 — остановись, не повторяй: 4 запроса подряд = блокировка на 3 часа.
- **Ozon**: лимиты щедрые (50 запросов в секунду), кроме двух мест: аналитика воронки — не чаще раза в минуту, финансы — период максимум 31 день.
- **Чего в API Wildberries нет вообще**: подменных артикулов и внешнего трафика. Отдачу от посева на WB по API не получить, только из кабинета. Не подменять это данными по поисковым запросам.

## 3. Как обновить дашборд

Обычный цикл — раз в неделю или раз в месяц:

1. Скачать свежие таблицы менеджеров из Google Sheets в `data/tables/` **под теми же именами** (01_…, 02_… и т. д.). Имена важны — сборщик ищет файлы по ним.
2. Скачать свежие выгрузки WB и Ozon туда же (07_, 08_, 09_).
3. Обновить снимки API в `data/api/` — это делает Claude по промпту из `PROMPT.md`, раздел «Обновление API».
4. Собрать:

```
cd engine
python3 build.py
```

Сборщик положит готовый `dashboard-influence.html` на уровень выше и напечатает
сводку: сколько записей, какие месяцы, где расхождения. Файл открывается двойным кликом.

Если структура таблиц поменялась (добавили/убрали колонки, переименовали листы) —
сборщик может ругнуться или молча недосчитать. Тогда — к Claude с `PROMPT.md`:
он поправит разбор под новую структуру.

## 4. Что важно знать до первого запуска

- **Заказы и регистрации нельзя складывать.** Товары считаются в заказах и CPO, боты — в регистрациях и цене регистрации. Это разные сущности, в дашборде они разведены фильтром «Тип».
- **План берётся только из общего медиаплана** (`05_mediaplan.xlsx`, лист «План упрощённый»). Планы во вкладках менеджеров как источник плана не используются.
- **Метки Ozon** у менеджеров бывают трёх видов: короткая ссылка `ozon.onelink.me/SNMZ/xxxx`, длинная onelink с параметром `c=`, прямая ссылка с `utm_campaign=`. Короткие надо раскрывать через браузер — раскрытые уже лежат в `shortlinks.json`. Искать метку надо по всему телу ссылки, а не только по хвосту: менеджеры оформляют по-разному.
- **Органика не берётся из таблиц.** Она считается: факт площадки за месяц минус внутренняя реклама, минус посев, минус самовыкупы.

Вся математика и все правила — в `LOGIC.md`.
