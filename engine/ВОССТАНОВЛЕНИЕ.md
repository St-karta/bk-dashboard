# Движок дашборда — как устроен (пересобран 02.10.2026)

## Что случилось
01→02.10 облачный контейнер сессии очистили. Вместе с ним пропали `build3.py`,
`attr.py`, `tpl.html`, кэш `api/*.json` и исходные выгрузки — они жили только

сборщик написан заново. Теперь всё лежит ЗДЕСЬ, в папке на компьютере.

## Файлы

| файл | что это |
|---|---|
| `build.py` | сборщик: таблицы + медиаплан + API → `records.json` |
| `mk.py` | подстановка данных в шаблон → `dashboard-influence.html` |
| `tpl.html` | шаблон страницы (вся вёрстка и подсказки) |
| `frozen.json` | **замороженные март–август** — 238 записей, не пересчитываются |
| `records.json` | результат сборки: заморозка + пересчитанные месяцы |
| `etalon_sep.json` | сентябрь из дашборда от 01.10 — для сверки после правок |
| `src/` | исходники: таблицы девочек, медиаплан, выгрузка Тильды |
| `api/` | кэш данных площадок |

## Как собрать

```
python3 build.py      # читает src/ и api/, пишет records.json
python3 mk.py         # собирает dashboard-influence.html
```

`build.py` падает с понятной ошибкой, если в медиаплане появился незнакомый
продукт или у Анастасии изменилась шапка — молча потерять данные нельзя.

## Заморозка истории

Месяцы март–август лежат готовыми в `frozen.json` и больше не считаются.
Это значит: даже если исходники за те месяцы потеряются — история цела.
Пересчитываются только месяцы из списка `LIVE` в начале `build.py`.
Когда октябрь закроется, его надо перенести в заморозку тем же способом.

## Что НЕ восстановлено

`attr.py` — расчёт модели для вкладки «Атрибуция публикаций». Вкладка работает
на замороженных данных (`api/attrib.json`, снимок 01.10) и помечена об этом
прямо на странице. Пересобирается вместе с доработками модели.

## Правила, чтобы не потерять снова

1. Движок живёт в этой папке. После каждой правки — копия сюда.
2. Вторая копия — в GitHub рядом с `index.html`.
3. Каждая присланная таблица сохраняется в `src/` с датой в имени.
4. Закрытые месяцы замораживаются и не зависят от исходников.
